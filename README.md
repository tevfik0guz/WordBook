# WordBook - Kelime Defteri - Tevfik Oğuz - 31. Dönem

## Proje Açıklaması

WordBook, kullanıcıların öğrendikleri yabancı
kelimeleri, anlamlarını ve örnek cümlelerini
kaydedebilecekleri kişisel bir kelime defteridir.

Uygulama sayesinde kelimeler eklenebilir,
düzenlenebilir, silinebilir ve aranabilir.

Veriler tarayıcının LocalStorage alanında
saklandığından sayfa yenilendiğinde kaybolmaz.

## Kullanılan Teknolojiler

- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Kurulum

1. Projeyi bilgisayarınıza indirin.
2. Terminalde proje klasörüne girin.
3. npm install komutunu çalıştırın.
4. npm run dev komutuyla uygulamayı başlatın.

## Yapay Zeka Kullanımı

Projenin geliştirilme sürecinde yapay zekadan
aşağıdaki aşamalarda yararlanılmıştır:

- Uygulamanın planlanması ve veri modelinin oluşturulması.
- React bileşenlerinin tasarlanması.
- LocalStorage kayıt ve veri yükleme
  fonksiyonlarının geliştirilmesi.
- CSS tasarımı ve responsive arayüz oluşturulması.
- Kodların açıklanması ve hata ayıklama.

## Veri Saklama

Kelime bilgileri LocalStorage üzerinde
JSON formatında saklanmaktadır.
